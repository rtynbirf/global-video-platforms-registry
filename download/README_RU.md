## Словарь статусов

- **active** — HTTP 200, сайт жив
- **active + antibot** — жив, отдаёт анти-бот страницу (401/403/405/429/451)
- **unverified** — ни HTTP, ни DoH, ни перекрёстные источники не дали однозначного ответа; UNKNOWN не считается подтверждением
- **merged** — слияние/ребрендинг, в поле `moved_to`/`notes` указан преемник
- **closed / unverified_dead / parked** — закрыт / вероятно закрыт (NXDOMAIN) / домен на парковке

## Контент-политика

По требованию заказчика исключены политические/пропагандистские платформы
(Rumble, Odysee, BitChute, Brighteon, Gab, Gan Jing World, Belsat, Espreso TV,

«Исключённые» в XLSX и `excluded_policy` в JSON.

## Правила отбора (без накрутки)

- Региональные версии глобальных платформ не считаются отдельными сервисами
- Пираты (Cuevana, Adjaranet и т.п.) и B2B-инфраструктура не включаются
- Метрики популярности не выдумываются; у каждой записи — метод и дата проверки
- Слившиеся сервисы не учитываются дважды

## Метод (кратко)

1. База заказчика (451) + 7 исследовательских пакетов (566 кандидатов) + второй проход 25.10.2026: 4 батча (Европа-2, Америки-2, АТР-2, глобальные вертикали) — 171 кандидат, 164 после дедупа
2. Дедупликация: полный хост → домен+имя → имя (снято 165 дублей, включая 5 исторических близнецов)
3. HTTP-проверка: 24-48 потоков, Chrome UA, до 6 редиректов, ретраи с вариантами URL
4. Кросс-проверка неоднозначных: WebSearch (офиц. страницы, Google Play, новости) + DNS-over-HTTPS
5. Статусы по консервативной шкале; исключения по контент-политике
