# Участие в проекте / Contributing

Спасибо за интерес к реестру! Правила простые и жёсткие — они и делают датасет доверенным.

## Как добавить платформу

1. **Проверь дубли:** домен не должен совпадать с активной записью (исключения — в DATA_DICTIONARY §2).
2. **Проверь живость:** HTTP-проба (можно `scripts/check_urls.py`) — 200-е или обоснованный `BLOCKED` (401/403/429/451).
3. **Источник обязателен:** официальный сайт, Wikipedia-статья с подтверждением запуска, PR компании или отраслевая новость 2025–2026.
4. **Политика:** пираты, B2B без потребительского слоя, политическая пропаганда и 18+ — не включаются (см. README §4).
5. **Заполни все 17 колонок** (DATA_DICTIONARY), `verified_date` — дата твоей проверки.
6. PR → CI прогонит аудит; без зелёного аудита мержа нет.

## Как сообщить об ошибке

Открой issue с шаблоном: `id` записи, что не так, ссылка-доказательство (жив/мёртв/ребрендинг). Изменения статуса принимаются только с доказательством: HTTP-вердикт, NXDOMAIN+DoH, официальное заявление, авторитетная статья.

## Этика

- Никаких выдуманных метрик и «примерно верных» статусов: пусто — значит пусто.
- Ребрендинги трассируем (`moved_to`), а не удаляем.
- Политические и adult-платформы не вносятся в основную таблицу — только в `excluded_policy` с причиной.
